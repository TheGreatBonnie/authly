# Authly v0.4.0

**Release:** 0.4.0

## Highlights

- New token-based SDK authentication

## Breaking changes

API-key client authentication is deprecated.

### Before

```python
Authly(
    project_id="proj_demo",
    api_key="demo_key",
)
```

### After

```python
Authly(
    project_id="proj_demo",
    token="demo_token",
)
```

## Migration

A migration guide is required.
