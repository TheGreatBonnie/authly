# FAQ

## Is Authly production-ready?

No. Authly is a fictional benchmark application for testing Draftly.

## Does Authly support OAuth?

The initial SDK supports construction of an OAuth authorization URL. Full OAuth flows are planned for later simulated releases.

## Does Authly support roles?

Yes. Roles can contain permissions and can be assigned to users.

## Does Authly have persistent storage?

No. Version 0.1 uses in-memory state.
